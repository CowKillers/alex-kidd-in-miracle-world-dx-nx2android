# Perfil Android de referência

`android.tsv` é uma **cópia de referência** do arquivo gerado pelo
porter experimental durante o port (`status experimental`, pacote
`org.nx2a.t010025d01221a000`, orientação `landscape`).

Ele está aqui só como referência: o porter experimental **regenera**
esse arquivo (e o perfil provisório completo) a partir do survey do seu
próprio NSP. Não é preciso copiar este arquivo para lugar nenhum para
buildar — rode o porter com o seu próprio jogo e as suas próprias
chaves, como descrito no README principal.

O `game.tsv` do perfil provisório **não** está incluído de propósito:
ele é regenerado pelo porter e carrega build IDs do dump usado no port
original.
